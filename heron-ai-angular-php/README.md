# Heron AI — Angular + PHP standalone website

This folder contains the standalone Angular website and PHP contact-form endpoint. The full project archive is `heron-ai-angular-php.zip` in this folder.

## Local setup

1. Install Node.js 20+ and PHP 8+.
2. Run `npm install`.
3. Run `npm start` for the Angular development server.
4. Deploy the Angular build output and `php/contact.php` to a PHP-enabled web host.
5. Configure `HERON_TO_EMAIL` and `HERON_FROM_EMAIL` for PHP mail delivery.

Note: the project archive was checked for ZIP integrity. A full Angular build and live email delivery have not yet been verified.
